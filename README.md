# Real-Time Bank Transaction Fraud Detection Using Kafka & Machine Learning

## Overview
This project is a Real-Time Bank Transaction Fraud Detection System developed using Apache Kafka and Machine Learning techniques. The system continuously processes banking transaction data streams and identifies fraudulent activities in real time.

The project aims to improve banking security by detecting suspicious transactions in real time using data streaming and predictive analytics. Apache Kafka is used for real-time data ingestion and streaming, while Machine Learning models analyze transaction patterns to classify transactions as legitimate or fraudulent.



## Features
- Real-time transaction monitoring
- Fraud detection using Machine Learning
- Apache Kafka–based data streaming
- Fast transaction analysis
- Suspicious activity identification
- Scalable data processing pipeline
- Real-time prediction system
